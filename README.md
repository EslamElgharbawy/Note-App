## 📖 About

A simple and responsive note-taking application that allows users to create, edit, delete, and organize notes securely using Appwrite Authentication and Database.

---

## ✨ Features

- 🔐 User Authentication
- 📝 Create Notes
- ✏️ Edit Notes
- 🗑️ Delete Notes
- 🔍 Search Notes
- 📱 Fully Responsive Design
- ⚡ Fast Navigation with React Router
- ✅ Form Validation using Formik & Yup
- 🍞 Toast Notifications
- 🎨 Clean & Modern UI
